## Go/no-go and scaling rule

**GO**, with the narrow rule above. One annual ZIP can potentially cover 12 independent monthly release events. It is not a blanket authorization for every value in every workbook. A future annual import must repeat raw ZIP/member hashing, exact month/path binding, metadata inspection, January/mid-year/December cross-checks, and duplicate/conflict rejection.

No bulk importer was implemented.
