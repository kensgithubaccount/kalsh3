# M17 Bounded Autonomy — In progress

M17 began only after M16 passed its offline implementation gate. The initial architecture records evidence required to progress from a genuinely live-verified supervised canary toward later narrowly bounded operation.

The only autonomy state is `OFF`, even when every fixture flag is true. No credential, activation transition, production signer client, execution path, canary submission, or real-money order is added. Live canary, reconciliation, strategy evidence, signer runtime, PostgreSQL concurrency, and explicit human governance remain mandatory future evidence.
